## Существующие решения

| № | Источник | Подход | Материал | Результат | Чем не подходит нам |
|---|---|---|---|---|---|
| 1 | https://aclanthology.org/2026.lrec-1.84/| RuBERT (трансформер) + классические ML-классификаторы + instruction-based LLM (YandexGPT); 127 лингвистических признаков| 7322 коротких фрагмента (15-30 слов) из учебников РКИ, размечены по CEFR экспертами| Лучший результат - RuBERT: F1 = 47.8%, MAE = 0.56| Работает только на очень коротких фрагментах (15-30 слов), а не на целых текстах; результат (F1 ~48%) ниже нашего порога неработоспособности (Accuracy ≤ 0.50) - то есть даже специализированная модель с огромным набором признаков справляется неуверенно|
| 2 | https://journals.sagepub.com/doi/10.3233/JIFS-179007| Классические статистические фичи текста + 7 классификаторов / 4 метода регрессии (без нейросетей)| Russian Readability Corpus: учебники по социальным наукам + экзаменационные тексты РКИ| Ранжирование учебных текстов оказалось значительно проще, чем ранжирование естественных (не адаптированных) текстов| Не даёт единой готовой метки уровня и объяснения причин сложности, только сравнительное ранжирование текстов друг относительно друга, не абсолютную классификацию|
| 3 | https://huggingface.co/dksysd/cefr-classifier| Fine-tuned трансформер (DeBERTa-v3-large + LoRA), классификация на 6 классов CEFR| Параллельный корпус + instruction-датасет (состав в карточке не детализирован)| Числовые метрики в открытой карточке не приведены, только confusion matrix| Модель обучена и работает только для английского языка - для русского неприменима без полного переобучения; также не возвращает объяснение сложности (factors), только метку и уверенность|

> Источники: статьи, репозитории, модели на HuggingFace.
