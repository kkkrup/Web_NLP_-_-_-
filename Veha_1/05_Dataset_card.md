# Dataset card

**Срок:** веха 1

## Краткое описание

>RuAdapt состоит из текстов, адаптированных для изучающих русский язык как иностранный, и их оригинальных версий. Большинство материалов взяты из адаптированной литературы, любезно предоставленной издательством "Златоуст"

## Происхождение

**Источник:** публичный репозиторий Digital-Pushkin-Lab/RuAdapt на GitHub. Тексты: адаптированная художественная литература издательства «Златоуст» и оригиналы этих произведений (классика — Пушкин, Достоевский, Чехов; современные авторы — Акунин, Пелевин); энциклопедические статьи Гос. ИРЯ им. Пушкина; сказки, адаптированные в МГУ. **Способ получения:** скачивание готового набора из репозитория (git clone / загрузка архива). Сами авторы извлекали текст книг из PDF (Apache Tika), чистили скриптом на Python и выравнивали автоматически (Bleualign и CATS). **Дата сбора:** авторами — 2020–2021 гг. (публикации: BSNLP, апрель 2021; «Диалог», июнь 2021). Нами — ⟨дата скачивания⟩, коммит ⟨хэш⟩. **Критерии отбора:** берём версию CATS по параграфам (лучшее качество выравнивания на ручной разметке: F1 0,98 против 0,90 у Bleualign; есть оценка близости для фильтрации). Параграфы — потому что уровень сложности осмысленно оценивать на связном фрагменте, а не на изолированном предложении. **Скрипт сбора:** ⟨ссылка на ноутбук / load_ruadapt.py в репозитории команды⟩

## Правовые основания

**Правовой режим источника:** в репозитории не указана лицензия (файла LICENSE нет). Без лицензии по умолчанию все права сохраняются за правообладателями. Адаптации — авторские тексты «Златоуста», часть оригиналов (Акунин, Пелевин) тоже охраняется авторским правом. Сами авторы в статье писали, что публикуют данные для исследовательских целей в той мере, в какой позволяют права. Наш режим использования: только учебно-исследовательский, без повторного распространения текстов (в наш репозиторий и в веб-сервис корпус не выкладываем, храним ссылку и скрипт загрузки), обязательная ссылка на публикации авторов.  
**Содержит ли сведения о людях:** нет  
**Если да — как обезличено:** не требуется. В текстах есть имена персонажей и исторических лиц (энциклопедические статьи), но это не персональные данные субъектов.

## Подготовка

**Нормализация:** приведение кавычек и тире к единому виду, удаление лишних пробелов и переносов, остатков разметки после извлечения из PDF; регистр сохраняем (важен для признаков); ё не заменяем.
**Дедупликация:** точные дубликаты по нормализованному тексту + удаление повторов, возникших из-за выравнивания «один ко многим» в CATS (один оригинальный параграф сопоставлен нескольким адаптированным и наоборот: у авторов на 9 352 пары приходилось 7 671 уникальный оригинальный параграф). Для каждого повторяющегося параграфа оставляем пару с максимальной близостью. Доля удалённого ⟨посчитать⟩.
**Объём до и после:**  до — 11 265 пар параграфов; после — ⟨посчитать⟩.

**Три найденных дефекта данных:**

1. **Что:** выравнивание «один ко многим» — одни и те же параграфы встречаются в нескольких парах, что дублирует примеры и может дать утечку между train и test. **Что сделали:** оставили по одной паре на параграф (максимальная близость CATS), повторно проверили дубликаты по тексту.
2. **Что:** шум извлечения из PDF и очень короткие или служебные параграфы (повторяющиеся реплики вроде «Пауза.» в пьесах, обрывки строк, номера глав). Такие фрагменты не несут информации об уровне. **Что сделали:** удалили параграфы короче ⟨N⟩ токенов и строки без кириллицы; пороги фиксируем в скрипте.
3. **Что:** неточные метки уровня — у части пар указан диапазон (B1-B2), а сборники рассказов отнесены сразу к B1–C1. Кроме того, уровень присвоен целой книге, а не отдельному параграфу.**Что сделали:** диапазоны сводим к классам по правилу из раздела «Разметка»; пары из сборников с широким диапазоном исключаем из обучения (или выносим в отдельный проверочный набор).  

## Разметка
Откуда берётся: смешанно — уровень из источника (присвоен издательством / авторами адаптации), сведение к классам — наше правило.

Правила отнесения:

класс = уровень, указанный для адаптированного параграфа (A2, B1, B2, C1);
диапазон из двух соседних уровней (A2-B1, B1-B2) → ⟨решение команды: относим к нижнему уровню / выделяем промежуточный класс / исключаем⟩;
оригинальные параграфы → класс «оригинал (неадаптированный текст)» либо не используются. Уровень оригиналу не присвоен, приравнивать его к C1–C2 без проверки нельзя.

Кто размечал: уровни задавали профессиональные авторы-адаптаторы РКИ («Златоуст») и исследователи ГосИРЯ и МГУ; ручной разметки командой нет. Правила отнесения: см. выше. Три разобранных спорных случая:

Пара с меткой «B1-B2»: текст адаптирован на границе уровней — по нашему правилу ⟨…⟩.
Сборник рассказов с диапазоном B1–C1: метка слишком широкая для обучения — исключаем.
Короткий параграф из адаптации B2, совпадающий с оригиналом слово в слово (адаптатор его не менял): формально B2, но такой же текст есть в классе «оригинал» — оставляем одну копию и не включаем пару в класс «оригинал».

**Принцип разделения:** по текстам (group split по произведению / статье), со стратификацией по уровню, насколько это позволяет число текстов на уровень. Все параграфы одного произведения — и адаптированные, и оригинальные — попадают в одну часть. Случайное разделение по параграфам недопустимо: модель выучит стиль конкретной книги или автора, а не уровень сложности. 
**Проверка на утечку:** (1) пересечение множеств text_id между частями = 0; (2) нет точных дубликатов нормализованных параграфов между частями; (3) выборочная проверка почти-дубликатов (косинусная близость TF-IDF > 0,9) между train и test.

## Ограничения

> Обязательный раздел.

**Систематические перекосы:** источник — более двух третей данных из одного издательства («Златоуст»): классификатор выучит его редакционный стиль адаптации;
жанр — в основном художественная литература, преимущественно классика XIX — начала XX века (архаичная лексика, авторский стиль); энциклопедические статьи сильно отличаются по жанру и смешивают признак «жанр» с признаком «уровень»;
категория — дисбаланс уровней с преобладанием B1, мало A2, нет A1 и C2;
метки — уровень присвоен книге целиком, отдельные параграфы внутри книги могут быть проще или сложнее заявленного уровня. 
**Для чего набор непригоден:**  для определения уровня A1 и C2; для оценки текстов других жанров (новости, учебные диалоги, деловые тексты) без дополнительной проверки; для оценки текстов, написанных учащимися (это адаптированные тексты для чтения, а не тексты учеников); для повторного распространения текстов (лицензия не указана).
**Что осталось спорным:**  как обращаться с диапазонами уровней (A2-B1, B1-B2) и с оригиналами (отдельный класс или исключение); корректно ли объединять литературный и энциклопедический подкорпусы в одну обучающую выборку; достаточно ли текстов на редких уровнях для разделения по произведениям.
