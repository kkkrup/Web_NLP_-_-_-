# API моего сервиса

Контракт: что сервис принимает и что отвечает. Совпадает с документом команды
`04_Контракт_API.md` версии 1.1. Код (`main.py`) и этот файл должны совпадать.

**Название сервиса:** Классификатор сложности текста для РКИ
**Что делает:** определяет уровень сложности русского текста для изучающих русский как иностранный — A (A1–A2), B (B1–B2) или C (C1–C2) — и показывает, что делает текст сложным.
**Автор:** Крупчатникова Варвара (веб-часть); команда проекта

Адрес локально: `http://127.0.0.1:8000`, документация: `http://127.0.0.1:8000/docs`.

## POST /api/analyze

Разбирает присланный текст в выбранном режиме. Основной режим — `complexity`.

**Запрос**

```json
{
  "text": "Вчера вечером я долго разговаривал с преподавателем о будущей работе, и он посоветовал мне обязательно подготовиться заранее. Это было очень полезно.",
  "lang": "ru",
  "mode": "complexity"
}
```

| Поле | Тип | Обязательно | Ограничения |
|---|---|---|---|
| `text` | строка | да | от 3 слов до 5 000 символов; не пустой и не из одних пробелов; не менее 50 % букв — русские |
| `lang` | строка | нет | только `"ru"`, по умолчанию `"ru"` |
| `mode` | строка | нет | один из режимов ниже, по умолчанию `complexity` |

**Ответ 200**

```json
{
  "ok": true,
  "result": {
    "level": "B",
    "score": 43,
    "all_scores": { "A": 0.193, "B": 0.709, "C": 0.098 },
    "factors": { "long_sentences": 1, "rare_words": 9, "syntax_depth": 1.5 },
    "highlights": {
      "long_sentences": [{ "start": 0, "end": 125 }],
      "rare_words": [
        { "word": "вечером", "start": 6, "end": 13 },
        { "word": "разговаривал", "start": 22, "end": 34 },
        { "word": "преподавателем", "start": 37, "end": 51 },
        { "word": "будущей", "start": 54, "end": 61 },
        { "word": "посоветовал", "start": 75, "end": 86 },
        { "word": "обязательно", "start": 91, "end": 102 },
        { "word": "подготовиться", "start": 103, "end": 116 },
        { "word": "заранее", "start": 117, "end": 124 },
        { "word": "полезно", "start": 141, "end": 148 }
      ]
    }
  },
  "meta": { "chars": 149, "mode": "complexity", "took_ms": 0.4 }
}
```

Это ответ заглушки на текст из запроса. `result` зависит от режима (см. ниже). Поля `meta`:

| Поле | Тип | Описание |
|---|---|---|
| `meta.chars` | integer | число символов в присланном тексте |
| `meta.mode` | string | в каком режиме сделан разбор |
| `meta.took_ms` | number | время обработки на сервере, мс |

**Ответы с ошибкой.** Тело всегда одного вида:

```json
{ "error": "text_too_long", "message": "Текст длиннее 5000 знаков", "limit": 5000 }
```

| Ситуация | `error` | HTTP |
|---|---|---|
| пустой текст или только пробелы | `empty_text` | 400 |
| текст длиннее 5 000 символов | `text_too_long` | 400 |
| `lang` не `"ru"` или русских букв меньше половины | `unsupported_language` | 400 |
| меньше 3 слов | `text_too_short` | 400 |
| нет поля `text`, оно не строка, тело не JSON | `invalid_request` | 400 |
| режима `mode` нет в списке | `unknown_mode` | 400 |
| модель не загрузилась | `model_unavailable` | 503 |

Поле `limit` есть только у `text_too_long`. Интерфейс показывает `message` пользователю как есть.

Проверки идут в порядке таблицы. Ответ 422 этот эндпоинт не даёт: ошибки проверки Pydantic переведены в `400 invalid_request`, чтобы у интерфейса был один формат ошибок.

## Режимы анализа

| Режим | Что возвращает в `result` |
|---|---|
| `complexity` | **основной.** `level` — `"A"`, `"B"` или `"C"`; `score` — сложность 0–100 (выше — сложнее); `all_scores` — вероятности классов `A`, `B`, `C`, в сумме 1; `factors` — `long_sentences` (число длинных предложений), `rare_words` (число редких слов), `syntax_depth` (упрощённая глубина синтаксиса); `highlights` — `long_sentences`: список `{start, end}`, `rare_words`: список `{word, start, end}` |
| `stats` | `words`, `unique`, `ttr`, `sentences`, `avg_sentence` |
| `freq` | `top` — список `{word, count}` (10 самых частых слов без служебных), и `total_counted` |
| `longest` | `words` — десять самых длинных слов по убыванию длины, и `max_length` |

В `highlights` поля `start` и `end` — позиции символов в исходном тексте (с 0, `end` не входит), то есть `text[start:end]` — нужный фрагмент. `factors.long_sentences` и `factors.rare_words` равны длине соответствующих списков. Списки могут быть пустыми.

Пока режим `complexity` работает на **заглушке** (`nlp.py`): значения условные, но считаются по тексту (длинное предложение — от 15 слов, редкое слово — длиннее 6 букв). После вехи 2 заглушку заменит модель NLP-части, формат `result` не изменится.

## GET /api/modes

Список доступных режимов — страница построит из него выпадающий список.

```json
{ "modes": ["complexity", "stats", "freq", "longest"] }
```

## Служебные эндпоинты

| Метод и путь | Ответ |
|---|---|
| `GET /api/health` | `{"status": "ok", "requests": 12}` — сервис жив, `requests` — сколько текстов разобрано с запуска |
| `GET /api/history?limit=10` | `{"history": [{"time", "text", "mode", "result"}, ...]}` — последние запросы, новые сверху; `text` обрезан до 80 символов; `limit` от 1 до 100, по умолчанию 10 |

История хранится в памяти сервера и обнуляется при перезапуске.

## Учебные эндпоинты (шаги 1–3)

| Метод и путь | Ответ |
|---|---|
| `GET /hello` | `{"message": "Hello, FastAPI!"}` |
| `GET /greet?name=Alex` | `{"message": "Hello, Alex!"}`; без параметра — `Hello, stranger!` |
| `POST /feedback` с `{"username", "comment"}` | `{"message": "Thanks for your feedback, Alex!"}` |

У них ошибки проверки остаются стандартными: FastAPI отвечает 422 сам.

## Что изменилось по ходу работы

- **v1.0 → v1.1 (09.11.2026).** Успешный ответ `/api/analyze` обёрнут в `{"ok", "result", "meta"}`; поля `level`, `score`, `all_scores`, `factors`, `highlights` не менялись и лежат внутри `result`. Причина: такой формат ответа требует шаблон курса веб-программирования (его проверяет `test_api.py`).
- Добавлено необязательное поле запроса `mode` (по умолчанию `complexity`) и учебные режимы `stats`, `freq`, `longest` из шаблона курса. Причина: шаги 4–5 шаблона.
- Добавлена ошибка `unknown_mode` (400) для неизвестного режима.
- Добавлены `GET /api/modes`, `GET /api/health`, `GET /api/history`.
