# Классификатор сложности текста для РКИ — веб-сервис

Учебный проект курса «Основы web-программирования», пары по теме FastAPI.
Сервис определяет уровень сложности русского текста для изучающих русский как иностранный: A (A1–A2), B (B1–B2) или C (C1–C2).

## Что внутри

| Файл | Зачем |
|---|---|
| `main.py` | веб-часть: эндпоинты, проверка входных данных, коды ответов |
| `nlp.py` | анализ текста: функция `analyze(text, mode) -> dict`, про веб ничего не знает. Режим `complexity` пока заглушка |
| `API.md` | контракт сервиса: что принимает, что отвечает (совпадает с `04_Контракт_API.md` v1.1) |
| `test_api.py` | проверка из шаблона курса: делает запросы к работающему серверу и печатает, что готово |
| `test_contract.py` | проверка нашего контракта: коды ошибок, поля ответа, подсветки |
| `check_env.py` | проверка окружения |

## Запуск

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Сервер поднимется на http://127.0.0.1:8000. Документация и ручная проверка — http://127.0.0.1:8000/docs. Остановить: Ctrl+C.

## Проверка

Пока сервер работает, в **другом** окне терминала:

```bash
python test_api.py
python test_contract.py
```

Модуль анализа можно проверить и без сервера:

```bash
python nlp.py
```

Разделение ролей: `nlp.py` проверяет текст и поднимает `ValueError` с кодом ошибки из контракта (`"empty_text"`, `"unknown_mode"` и т. д.), а `main.py` превращает код в HTTP-ответ с текстом для пользователя. Поле `lang` в `nlp.py` не передаётся, его проверяет `main.py`.

## Пример запроса

```bash
curl -X POST http://127.0.0.1:8000/api/analyze ^
  -H "Content-Type: application/json" ^
  -d "{\"text\": \"Вчера вечером я долго разговаривал с преподавателем о будущей работе.\", \"mode\": \"complexity\"}"
```

(В Windows перенос строки — знак `^`, в Linux и macOS — `\`.)

Или из Python:

```python
import requests
r = requests.post("http://127.0.0.1:8000/api/analyze",
                  json={"text": "Вчера вечером я долго разговаривал с преподавателем о будущей работе."})
print(r.json()["result"]["level"])
```

## Замена заглушки на модель

После вехи 2 NLP-часть меняет в `nlp.py` блок режима `complexity`: вместо эвристики там будет вызов обученной модели. Она должна возвращать словарь ровно по контракту (поля `level`, `score`, `all_scores`, `factors`, `highlights`). Если модель не загрузилась, `nlp.py` поднимает `ModelUnavailable` — сервис ответит 503. `main.py` и страницу менять не нужно. После замены запустить `python test_api.py` и `python test_contract.py`.
